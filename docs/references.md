# 1. 제품 정의

> **올박스는 통이 보이는 팀 뽑기다.**

오리파의 문제는 확률이 낮은 것이 아니라 통이 안 보이는 것이다. 통이 안 보이면 확률은 검증 불가능한 주장일 뿐이고, 확률을 공개해도 그것이 참인지 확인할 방법이 없다.

| | 오리파 | 올박스 |
|---|---|---|
| 확률 고지 | 판매자 주장 (검증 불가) | 재고 ÷ 구좌. 통을 세면 확인됨 |
| 구성품 검증 | 불가 | 통 안의 전체 목록이 화면에 |
| 뽑힌 뒤 갱신 | 안 됨 (몰래 채워넣기 가능) | 빠진 만큼 확률이 실시간 갱신 |
| 안 나왔을 때 | 쓸모없는 카드 더미 | 팀 안에서 교환 |

# 2. 수식 유도

## 2.1 통과 개인 확률 — 정의

```
통(box)        N개 구좌
등급 g의 재고   K_g 장,   Σ K_g = N
개인 1회 추출   P(g) = K_g / N
```

이것은 수식이 아니라 정의다. 근거가 필요 없다. 그리고 이것이 오리파와의 차이 전부다 — 오리파는 `K_g`를 공개하지 않으므로 `P(g)`를 계산할 수도 검증할 수도 없다.

## 2.2 팀 확률 — 초기하분포

팀 n명이 같은 통에서 각자 1구좌씩 뽑는다. **비복원 추출**이다.

팀 안에 등급 g가 최소 한 장 나올 확률:

```
                    C(N − K_g, n)
P_team(g, n) = 1 − ───────────────
                      C(N, n)
```

**초기하분포**(hypergeometric distribution)다. 유한 모집단에서 비복원으로 n개를 뽑을 때 특정 성공 원소가 포함될 확률이며, 확률론의 표준 분포다. 가정이 아니라 정의에서 따라 나온다.

### K_g = 1인 경우 — 정확히 n배

```
C(N−1, n)     N − n                          N − n      n
─────────  =  ─────      →    P_team = 1 − ───────  =  ───
 C(N, n)        N                              N         N
```

```
혼자   P = 1/1,000 = 0.100%
10명   P = 10/1,000 = 1.000%      ← 정확히 10배
```

재고가 1장이면 팀 인원 n에 대해 정확히 n배다. **회사가 아무것도 보태지 않는다.**

### K_g > 1인 경우 — 거의 n배

```
C(N−K, n)    K−1   N − n − i
─────────  = ∏   ───────────
 C(N, n)     i=0     N − i
```

A등급(K=4), N=1,000, n=10:
```
(990/1000)(989/999)(988/998)(987/997) ≈ 0.96059
P_team ≈ 3.941%      혼자 0.400% 대비 9.85배
```

정확히 10배가 아니라 9.85배다. **이 차이를 화면에 그대로 표시한다.** 반올림해서 "10배"라고 쓰지 않는다.

### 구현 주의

큰 이항계수는 오버플로한다. `C(N−K,n)/C(N,n)`을 직접 계산하지 말고 곱 형태 `∏(N−n−i)/(N−i)`, `i=0..K−1`로 계산한다. 로그 감마 함수 계산과 대조해 수치 안정성을 검증한다.

## 2.3 팀 확률이 개인 확률이 되는 지점 — 교환

**팀에 S가 나오는 것과 내가 S를 갖는 것은 다르다.** 교환이 없으면 팀이 아무리 커져도 개인 확률은 `K_g / N` 그대로다. 팀 효과는 존재하지만 나에게 도달하지 않는다.

```
교환 없음:  내 확률 = K_g / N                   (n과 무관)
교환 있음:  내 확률 → P_team(g, n) 쪽으로 이동    (n에 비례해 증가)
```

**교환이 팀 확률을 개인 확률로 전환하는 장치다.** 이것이 "왜 공동구매인가"에 대한 답이다. 확률을 올려주는 서비스라서가 아니라, 교환 없이는 팀이 아무 의미가 없기 때문이다.

### 정직한 한계

전부 전환되지는 않는다. 같은 카드를 여러 명이 지목하면 한 명만 가진다. 실제 전환율은 지목 분포에 의존하므로 **닫힌 형태의 식이 없다.** 시뮬레이션으로 측정하고 그 표를 화면에 그대로 띄운다.

```
n=10, K_S=1, S를 지목한 사람이 k명일 때 내가 S를 최종 보유할 확률
  k=1  →  측정값
  k=3  →  측정값
  k=10 →  측정값 (전원이 같은 걸 원하면 전환 효과 없음)
```

## 2.4 비복원 추출이 천장을 대체한다

도박사의 오류는 "많이 안 나왔으니 이제 나올 때가 됐다"는 착각이다.

**복원 추출이면 착각이다.** 매번 독립이라 확률이 안 변한다. 오리파는 심지어 꽝카드를 다시 채워넣기까지 한다(근거 B5).

**비복원 추출이면 참이다.**

```
N=1,000, K_S=1.  j구좌가 이미 뽑혔고 S가 안 나왔다면

           K_S           1
P(S) = ─────────  =  ─────────
        N − j         1000 − j

j=0    0.1000%
j=500  0.2000%   (2배)
j=900  1.0000%   (10배)
j=990  10.0000%  (100배)
```

천장이라는 인위적 장치가 필요 없다. 통을 보여주고 비복원으로 뽑으면 도박사의 오류가 저절로 참이 되고, 그 사실이 화면의 숫자로 계속 증명된다. 별도 파라미터도, 계정도 필요 없다.

## 2.5 교환 — Top Trading Cycles

```
입력    각 참여자 i:  보유 o(i),  선호 순위 P(i)
알고리즘
  1. 각 i가 자기 최선호를 가진 사람을 가리키는 유향그래프 구성
  2. 사이클을 찾아 그 사이클을 따라 한 바퀴 돌린다
  3. 사이클에 속한 참여자를 제거하고 1로 돌아간다
출력    배정 μ
```

선호 순위 구성:
```
1순위      지목한 카드
2순위 이하  ChatGPT가 대화로 생성한 순위 (사용자 수정 가능)
누락분     크롤 시세 내림차순으로 서버가 채움
```

### 보장되는 성질

| 비공허성·유일성·파레토 효율 | 더 나은 배정이 존재하지 않음 | Roth & Postlewaite (1977) |

### 응용 맥락

이 모형은 생체 장기이식(신장 교환), 공공주택 배정, 학교 선택에 실제 적용된다. 각 참여자가 불가분재 하나를 보유하고, 금전 이전 없이, 자기 보유물의 재산권을 유지한 채 재배분하는 문제 — **중복 카드 교환과 수학적 구조가 정확히 같다.**

# 5. 인용 시 주의

1. **원문을 확인하고 인용할 것.** 서지는 검색 결과에서 취합했다. 특히 D5(Wang et al. 2018)와 D3(Shen et al. 2024)은 초록을 직접 확인하지 못했다.
2. **나무위키·커뮤니티는 근거가 아니다.** B5·B6은 "커뮤니티에서 반복 지적되는 문제"로 명시하고, 주장 자체는 B1(언론)으로 지탱한다.
3. **상관관계를 인과로 쓰지 말 것.** D6의 r=0.26은 횡단 자료 기반이고 원저자들도 인과를 주장하지 않는다.
4. **중국 표본의 일반화 한계.** D1·D4 모두 중국 소비자 표본이다. 한국 적용은 가정이다.
5. **불리한 결과도 적을 것.** D2는 우리 제품 전제에 불리한 결과다. 그대로 적는다.
6. **TTC 전략 방지는 표본 검사이지 전수 증명이 아니다.**
7. **"Shapley-Scarf의 알고리즘"이라고 쓰지 말 것.** Gale의 것이다.
