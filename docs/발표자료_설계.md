# 발표자료 설계서 (내부용)

과제 1의 제출물은 **발표자료**다. 이 문서는 그 덱을 만들기 위한 작업 명세서이고,
외부 공개용 보고서가 아니다. 목적은 두 가지다.

1. **슬라이드에 들어갈 모든 수치의 출처를 한 곳에 고정한다.** 덱에 손으로 타이핑한
   숫자가 하나도 없어야 하고, 각 수치가 어느 실행 출력에서 나왔는지 여기서 확인된다.
2. **22장의 서사 흐름을 설계한다.** 과제가 요구하는 세 가지(컬처 시그널 · 현상 분석과
   문제 정의 · 제품 아이디어와 MVP)가 어느 장에서 답해지는지 대응시킨다.

덱 파일: `../발표자료_올박스.tex` → `xelatex` 2회 → PDF
스크린샷: `node tests/shots.mjs https://albox-alwayz.vercel.app ../images` (배포본에서 직접)

## 2. 서사 — 이 덱이 증명하려는 것

세 문장으로 요약된다.

1. **포켓몬 카드는 실제로 화제였다.** 기사만 인용하지 않고 12개월 시세를 직접 수집해
   같은 상승을, 같은 달에, 독립적으로 확인했다.
2. **그 안의 문제는 낮은 확률이 아니라 검증 불가능성이다.** 가치가 상위 등급에 쏠려
   있다는 것은 논문이 실측했고(19.1%→58.8%), 그래서 생긴 오리파는 확률을 아예 적지
   않는다는 것은 우리가 실측했다(0/37). 호주 인터뷰 연구가 같은 구조를 독립적으로 말한다.
3. **올박스는 확률을 검증 가능한 사실로 바꾼다.** 구성 1,000장을 전부 그리고,
   뽑히면 빼고, 안 나오면 팀 안에서 바꾼다. 세 형식이 같은 규칙을 쓰는데 ①과 ③이
   **반대 방향**으로 움직이는 것이 팀 효과가 마케팅이 아니라 구조라는 증거다.

### 반드시 피할 것

- **"통"** — 내부 용어. 화면·문서에서 이미 제거했다. 덱에도 쓰지 않는다. → 구성 / 박스 / 재고
- 희소성 압박 어휘(얼마 안 남·서두르·마감 임박) — I10 위반
- 표에 없는 숫자, 반올림한 배수(9.87배를 10배로 쓰지 않는다)
- 내부 회계(참여자당 마진·재원) 공개

### 장별 메모

- **5장**은 이 덱에서 가장 강한 슬라이드다. 남의 기사가 아니라 우리가 수집한 시계열이고,
  변곡점(2026-04)을 코드가 데이터에서 유도했다. pgfplots로 벡터 렌더 →
  `docs/trend-data.tex`의 `\trendCoords`를 그대로 쓴다.
- **6장**의 교차검증이 5장의 무게를 만든다. 두 기사와 우리 데이터가 같은 달을 가리키는데,
  우리는 그 기사를 보고 수집 기간을 정한 것이 아니다.
- **8→9→10장**이 문제 정의의 삼단이다. 논문이 구조를 실측(8) → 우리가 그 구조의 결과를
  실측(9) → 다른 나라 질적 연구가 같은 메커니즘을 말함(10).
- **14장**이 제품 파트의 핵심 논증이다. 같은 규칙에서 방향이 갈리는 것이 팀 효과의 증거다.
- **17장**은 "AI/지목이 장식이 아니다"를 수치로 보인다. 선호가 같으면 교환이 죽는다.
- **21장**에서 반드시 말할 것: 확률 리터럴이 화면 소스에 있으면 검사가 깨진다.
  즉 "지어내지 않았다"가 주장이 아니라 **테스트로 강제**된다.
- **22장** 한계: 타깃은 추론이고 인터뷰를 안 했다 / 통 원가를 소매가로 뒀다 /
  ②③은 집계를 저장하지 않는다 / 실결제·배송 미구현.
